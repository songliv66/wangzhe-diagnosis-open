# 给小禾的中路起步诊断

## 证据范围
本报告只依据这份合成问卷。你自述最高黄金二，主玩中路，常用妲己和安琪拉，每次约20分钟；没有提供录像、战绩或当前版本资料。以下是待验证的训练假设，不能当作已经看见你漏了多少兵、支援多慢或技能命中率低。

## 先把一个选择做清楚
你的目标是两周内说清楚“为什么离开中路”，比同时学习多个英雄更容易复查。现阶段优先把注意力放在离开线路前的一次判断，而不是再背更多连招。你说“清完线就跟着跑、回来又丢兵”，提示需要核查的是离线时机与回线计划；它还不足以证明所有游走都错了。

## 三个优先核查的问题
### 1. 离开前有没有明确去处
下次准备离开中路时，先说出目的：接近哪一侧、帮助谁、满足什么条件才继续。若只知道“那边打起来了”，但看不清人数和撤退路线，就先留在安全位置补信息。若队友已经撤退或目标消失，及时放弃原计划。复盘时只看这一次决定，记录当时可见的事实。

### 2. 回线是提前安排还是事后想起
问卷说回去时会丢兵，但不知道是何种兵线和时间。下一局离开前先想好“什么情况马上返回”；到达目的地后再看一次原线路是否出现必须处理的情况。不要为了完成一次游走而一直等机会。暂不要求你精确背刷新秒数，先确认自己有没有回线计划；具体兵线规则再由教练结合当时版本核验。

### 3. 紧张时能否把信息缩成两项
小地图上的打架会让你紧张。练习只回答“我现在看见了谁”“我能安全走哪条路”，不知道就标记未知。这样可以把“我要立刻帮忙”的压力变成可检查的信息问题。它是训练注意力的方法，不保证每次判断正确。

## 接下来五次练习
- 第一次：继续使用你较熟悉的一个英雄，选一次离线，结束后写一句出发理由；胜负不影响完成。
- 第二、三次：离开前增加一个返回条件，例如队友撤退或目标已结束；赛后各找一个仍想不通的片段。
- 第四、五次：比较两次选择，写下哪个信息改变了决定。没有时间回看整局时，只保留你自己记住的一个时刻，标明记忆可能不准。

先不同时练新英雄。20分钟包含准备和复查时，一天做完一个小任务就够；没有足够时间开始完整对局时，可以只整理上一次的问题，不为凑次数仓促开局。

## 两周后怎样判断有进步
请带回三条“当时知道什么、选了什么、什么条件会改变选择”的记录。如果你能解释选择，就有了下一步看录像的入口；若仍只记得输赢，先让教练陪你从一段获授权录像找出决策点。没有录像前，本报告不判断真实操作水平，也不承诺两周能升到某个段位。
