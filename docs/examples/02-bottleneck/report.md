# 给阿岚的辅助游走诊断

## 依据与未确定的部分
你自述主玩辅助，最高王者18星、巅峰1650，张飞和太乙真人较熟悉；每周约6局，每局可写5分钟记录，周末复查30分钟。你没有提供本次录像。队友在你离开后阵亡只是结果，不能直接证明离开决定错误，更不能证明你视野差、射手不会玩或某个英雄当前版本弱。

## 核心训练方向
这次瓶颈更适合从“离开时掌握了什么”开始核查，而不是用最后有没有人阵亡给整次游走打分。你说自己觉得下路安全，却没有出发信息的记录；我们需要先知道“安全”包含了哪些可见条件，才决定是否应改选择。先保留现有熟悉英雄，把变量留给决策本身。

## 三个可检验的假设
### 1. “安全”的定义可能不稳定
下一次游走前，写或回忆三件事：线上双方位置、当时看见的威胁、自己计划何时回来。看不见的人要记成未知，不能补成“应该不在”。如果关键威胁未知且线上队友没有安全撤退空间，可以选择缩短移动距离、继续观察或暂留；如果信息足够且目标明确，再考虑离开。这些是条件性选项，不是每局固定答案。

### 2. 可能只复盘了对方死亡后的信息
赛后面板无法还原离开瞬间看见的内容。每局只选一次最纠结的出发，在5分钟里写“当时知道”“当时未知”“出发目的”“返回条件”。记录不全时如实写忘了。若以后补录像，再检查记忆与画面是否一致；不要因为后来知道敌人在哪，就把那个信息倒填进当时的决定。

### 3. 逆风的目标还不够具体
“保护还是找机会”太大，先拆成眼前能做的一件事：保护某个人处理一波安全资源，或等一个明确可见的配合窗口。窗口消失、队友无法跟进或撤退路线不明时，就重选目标。没有具体时间点、经济和人员状态，不能在本问卷里断言你该开团还是保人。

## 三周的行动安排
- 第一周：6局中每局只留一次游走记录，先观察自己使用哪些信息，不要求减少出发次数。
- 第二周：从第一周最常遗漏的一项中只选一项，出发前主动检查。每局记“检查了／忘了／信息不可得”，不把后两类算成同一种错误。
- 第三周：周末从记录里选两次不同结果但信息相似的决定，请教练比较选择依据。条件允许时配一段获授权录像；不公开队友信息。

## 什么结果会改变建议
如果录像显示你离开前已完整观察、返回也及时，训练可能转向沟通或团队预期；如果记录本身长期写不出威胁与目的，再继续缩小观察任务。下一步是否学习孙膑，需要结合你的兴趣和当前机制材料决定，这里不凭英雄名称给强度结论。过程记录能帮助教练定位问题，但6局样本不足以保证胜率、星数或巅峰分变化。
