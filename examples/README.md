# 三个完整的合成案例

| 示例 | 展示重点 |
|---|---|
| [01 新手完整问卷](01-beginner/) | 自述依据、一次离线的选择、两周过程记录 |
| [02 已有玩家瓶颈](02-bottleneck/) | 辅助游走、结果与决策信息的区别、三周复查 |
| [03 缺失与冲突](03-ambiguous/) | 时间冲突、位置未定、未回复时保留条件分支 |

每例都有原始输入、可复制提示词、预写追问、实质诊断与真实排版文件。诊断文本是作者为展示工作流写的模拟答复，不是自动诊断器输出，不是模型性能基准。工具真实完成的是输入机械核查、同内容 Markdown/PDF/PNG 生成及指纹校验。

在仓库根执行 `python3 scripts/run_demo.py --output-dir outputs/demo-first` 可从原始 JSON 重新核查全部案例，再重排版三份预写诊断。结果写入新目录，不读取已生成 PDF，也不覆盖仓库内已展示文件。需要新诊断时让模型阅读新问卷、遵循 SKILL.md 编写新 Markdown，再运行渲染器。
