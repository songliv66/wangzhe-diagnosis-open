# Markdown 是正文真源

渲染器接受 UTF-8 `.md`（1-30,000 字符），支持 `#`、`##`、`###` 标题、空行分段以及 `- ` 简单列表。其他 Markdown 语法以可见纯文本处理；不执行 HTML、脚本、图片下载或内嵌指令。PDF 中不自动增加诊断、分数或结论。

示例结构可按问题调整：证据范围、已知自述、主判断、三个待核查问题、下一次练习、复查方式、条件与边界。长内容自动形成单页纵向报告，PNG 同源导出；为避免不可读的超长图片，总高度超过 14,000 PDF 点会要求拆分报告。

输出目录必须尚不存在，防止已有订单被覆盖。成功时包含 `report.md`、`report.pdf`、`report.png`、`manifest.json`；图片默认宽 2160 像素，报告是嵌入中文字体的真实文字 PDF。manifest 记录输入、配置和产物 SHA-256、图片尺寸、文字提取和生成环境版本。原始问卷不自动复制。

检查只证明本次文件存在、指纹对应、PDF 提取含正文及 PNG 尺寸；教练仍应检查语义、隐私和图片细节。换输入或换配置须重新运行到新目录，旧 manifest 和旧结论只对应旧输入。

导出后可运行 `python3 scripts/check_output.py <输出目录> --source <原始Markdown>`，再次核对哈希、大小、图片尺寸与PDF文字，并发现正文修改后旧产物已失效。它不核查诊断正确性。
