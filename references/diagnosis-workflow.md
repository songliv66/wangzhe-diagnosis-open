# 从自述到训练建议

1. 把自述与未提供证据列开：段位、位置、目标、具体困难、时间、既往方法。问卷没有录像就没有观察过的对局表现。
2. 对矛盾只问决定训练方案的关键项。暂时得不到答复时，可交条件分支，不能替答卷人选一个事实。
3. 按影响与可验证性选至多三个训练假设，每个给出答卷依据、仍不确定之处、下次可观察的现象。避免“意识差”等无法操作的标签。
4. 给一个具体动作和停止/改选条件。例如准备游走前看兵线与可见人数；人数未知且撤退路线不明时先留线。它是一般训练原则，不是某版本的最优答案。
5. 练习时间少就缩小目标；把成败指标写成过程记录（是否检查、是否回看、是否能解释），不把胜率、星数当短期保证。
6. 交给教练审核，确认用词与学生承受量；模型不会替代教练看录像。

材料归属：教练的原创材料可按其许可使用；第三方文章、视频、课程和游戏素材不因配置一个来源链接就获得再分发权。正文若需要具体技能或版本细节，应先从获授权、可核验的资料确认并注明版本。公开包不含付费教学、游戏截图、角色图片或游戏数据。
